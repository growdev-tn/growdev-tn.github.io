## Rules and gotchas

- Edit `src/` only. `site/index.html`, `site/ar/index.html`, `site/en/index.html`, `site/assets/js/dict-*.js`, sitemap, robots and llms files are generated.
- Share images: `tools/og.html` → `npm run og` (needs Playwright, developer machine only; the host comes from `src/site.json`). The build fails if `og-<lang>.jpg` is missing, and the checker fails if one was made for another host.
- `site/404.html` uses absolute paths: it works at the root of a host, which is where the site now lives. It would not work under a sub-path such as `…github.io/some-repo/`.
- GitHub Pages cannot set response headers; the CSP is a `<meta>` tag. Inline `style` attributes (60 in the French page, counted on 19 Nov) keep `style-src 'unsafe-inline'`.
- The browser-level test scripts (Playwright: behaviour of the theme button, axe scan, real-background contrast, header sweep from 320 to 1400 px, speed) lived in a scratch folder and are not part of the repo. Their results are in `docs/UX-AUDIT.md` (the Clients section and its carousel were tested the same way on 17 and 18 Nov). `tools/check.mjs` keeps the rules that can be checked without a browser.
- **Do not add a colour straight into a rule** (`#abc`, `rgba(…)`): the checker fails the build. Add a token to both theme blocks of `styles.css` and use `var(--name)`.
- **Theme and the first paint:** `boot.js` must stay a plain script in `<head>` (no `defer`). If it moves, the page flashes the wrong theme before settling.
- **`defaultTheme` `system`** makes the default follow the visitor's device; a visitor's own click always wins over it.
- **Never put `backdrop-filter`, `filter` or `transform` on `.site-header`.** It hosts the fixed mobile menu; any of them makes the header the menu's container and the menu shrinks to a 48 px strip once the page is scrolled (this happened in the original version; found on an iPhone 15 Nov 2026). The frosted bar is `.site-header::before`. The checker enforces it.
- **Client logos:** every logo sits on a white plate in both themes (`--logo-plate` is `#fff` in both token blocks, because the files have white backgrounds), is fitted with `object-fit: contain`, and is never recoloured (no filter, blend mode or opacity). Do not type `width` and `height` by hand: the build reads them from the file. The checker enforces all of this, and fails if a logo is missing, too heavy, has the wrong `alt`, or the three pages and `llms.txt` disagree with `src/site.json`.
- **Carousel:** the belt owns the plates' `transform`, so never give `.client` a `transform`, a `transition` or `data-reveal`; keep `touch-action: pan-y` on `.carousel__viewport` (without it a swipe cannot be told from a page scroll). With fewer than 4 clients a phone shows the still wall, on purpose. The checker enforces these.
- **Images:** an `<img>` with `width` and `height` attributes needs `height:auto` in any CSS rule that sets its width, or it is stretched (the About emblem was). The checker enforces it.
- Open the finished site on a real phone after every layout change, scrolled and not scrolled, with the menu open and closed. A desktop browser did not show the two defects above.
- **Technology logos:** add them only through `data-logo="id"` in the template; the build writes the image, its size, its version and the visible name. Each file in `site/assets/img/tech/` keeps its licence comment and stays under 6 KB. The credit line in the footer (`foot.logos`) must stay: the Git logo is CC BY 3.0 and needs it. Details: `docs/LOGOS.md`.
- **The simulator's formula is in three places:** the `WEEKS` constant in `calculator.js`, the visible equation and the `sim.how.*` texts. The checker compares them; change them together.
- **Never dim readable text with `opacity`.** The Method steps did (50% until reached), which failed the text contrast on phones; fixed on 24 Nov by changing only the marker and the title colour. A browser scan found it; the checker cannot.
- **Mail links:** both `mailto:` links in `#contact` carry a subject and a guided body, and each body ends by asking how the sender heard about GrowDev. The checker enforces it, and `docs/MARKETING-PLAN.md` §6 relies on that line to see which channel works without any tracker.
- **Placeholders:** `{{name}}` in the template must exist in `tools/build.mjs`, or the build fails. `data-i18n` replaces text up to the first closing tag of the same name, so keep it on elements with no children of the same name.
